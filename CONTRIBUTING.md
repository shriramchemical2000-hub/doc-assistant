# Contributing

Thanks for considering a contribution.

1. Create a feature branch.
2. Keep ingestion, retrieval, storage and UI responsibilities separate.
3. Add tests for behavior changes.
4. Run `pytest -q` before opening a pull request.
5. Never commit `.env`, private documents, database files or API credentials.
6. Update the relevant documentation.

For larger changes, open an issue first and describe the use case and proposed design.
